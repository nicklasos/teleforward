# Teleforward

A Python project template with testing infrastructure.

## Setup

1. Create and activate a virtual environment:
```bash
python -m venv venv
source venv/bin/activate  # On Windows: venv\Scripts\activate
```

2. Install dependencies:
```bash
make install
```

## Usage

- Run the project:
```bash
make run
```

- Run tests:
```bash
make test
```

- Run tests with coverage:
```bash
make test-cov
```
